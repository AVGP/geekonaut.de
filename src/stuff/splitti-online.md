**splitti.online** is an homage to the golden era of late-90s desktop computing and early personal homepages.

Instead of a standard scrolling landing page, visitors boot into **Splitti OS 98**, complete with desktop icons, a Start menu, an explorer that allows you to browse and view all sorts of files, like a photo gallery, weekly retros, and a personal diary.

## Highlights

* Built with **11ty** for static resilience.
* Draggable, resizable windows enhanced progressively on desktop while adapting cleanly to touchscreens on mobile.
* Includes `README.TXT`, `HOT_LINKS.TXT`, and dithered retro graphics.
