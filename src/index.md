Welcome to **geekonaut.de** — the personal corner of the web belonging to **Martin Splitt** (`@g33konaut` / `AVGP`).

I'm a friendly internet fairy, code magician, and Developer Relations Engineer at Google in Zurich, where I spend my days bridging web developers, search engines, and the open web platform.

When I'm not poking at browser rendering pipelines, WebGL shaders, or helping folks debug why their JavaScript framework ate their crawl budget, you'll probably find me **teaching scuba diving** in cold Swiss lakes or **making analog photographs** with historic chemical processes in the darkroom.

This site is built for **speed, fun, and resilience**: zero bloated frameworks, sub-second loads on slow connections, full support for **No-JS** browsing, and an interactive [~/terminal](/terminal/) where you can `cd`, `ls`, and `cat` through the entire site like a UNIX filesystem.
